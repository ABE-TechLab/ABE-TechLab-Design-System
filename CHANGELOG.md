# Changelog

All notable changes to this package will be documented here.

## 0.1.0 — initial development release

- Extracted ten theme palettes and Tailwind CSS v4 semantic token mappings.
- Added a machine-readable theme catalog and catalog consistency checks.
- Added an accessible React theme selector and `ActiveThemeProvider`.
- Added an optional `next-themes` adapter entry point for light/dark mode toggling.
- Added package build, typechecking, and GitHub Packages publishing workflows.

This version is still under validation and has not been published to GitHub Packages.
